# ON-NOTE
ON NOTE - Simple Windows To-Do List App
## ON NOTE 개인정보 처리방침

ON NOTE는 Windows용 할 일 목록 및 일정 관리 앱입니다.

사용자가 작성한 할 일과 일정은 기본적으로 사용자 기기에 저장됩니다. 현재 기본 기능은 회원가입이나 클라우드 동기화를 요구하지 않습니다.

사용자는 앱에서 작성한 내용을 수정하거나 삭제할 수 있습니다.

개인정보 관련 문의는 ON NOTE GitHub 저장소의 Issues에서 접수합니다.

https://github.com/nayun0817/ON-NOTE/issues
